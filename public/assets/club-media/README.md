# Portadas de clubes

Estas versiones WebP optimizadas se generaron desde imágenes del archivo `recursos.zip` compartido por el usuario para El Sendero del Soccer. Se prepararon sólo los clubes cuya foto se pudo identificar con confianza; los demás usan el escudo y los colores del equipo como portada gráfica. No se incluyeron imágenes de estadios.

La conversión reduce peso para la web y conserva intacto el archivo original. Los créditos y derechos de las imágenes fuente no se pudieron verificar de forma independiente.
