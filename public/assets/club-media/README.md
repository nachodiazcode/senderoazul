# Portadas de clubes

Las portadas WebP mezclan imágenes del archivo `recursos.zip` compartido por el usuario y fotografías de Wikimedia Commons con licencias abiertas. Hay una imagen identificada para cada uno de los 16 clubes de la Liga de Primera 2026. No se incluyeron imágenes de estadios.

La conversión reduce peso para la web. Las fotografías aportadas dentro de `recursos.zip` se conservaron como estaban y sus derechos no se pudieron verificar de forma independiente. En esta página, sus fuentes se distinguen de las imágenes con licencia abierta.

## Fotografías con licencia abierta

Las siguientes fotografías se adaptaron (recorte y conversión a WebP). Los enlaces de autor, archivo original y licencia también aparecen en la interfaz.

## Coquimbo Unido

`coquimbo-unido.webp` adapta la fotografía **“Coquimbo Unido campeón 2025”**, de **Cristian Avilés (Cavilese)**, obtenida desde [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Coquimbo_Unido_campe%C3%B3n_2025.jpg). Se redimensionó a 1800 × 1200 y convirtió a WebP para la portada. Licencia: [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/). La atribución y el aviso de adaptación aparecen junto a la imagen.
